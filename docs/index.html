Proyecto académico · MVP

CryptoInsight

Consulta, almacenamiento y visualización de precios históricos de criptomonedas usando Binance, FastAPI, SQLite y Streamlit.

Ver repositorio Leer documentación

Qué incluye

  • Velas diarias públicas sin API key ni login.
  • Filtros por moneda y rango de fechas.
  • Indicadores, rendimientos, volumen y gráficas.
  • Persistencia local e ingestiones sin duplicados.

Probarlo

GitHub Pages sirve esta portada, pero no ejecuta Python. Para abrir el dashboard interactivo clona el repositorio y ejecuta:

./run-mvp.sh

Después visita http://127.0.0.1:8501.

Alcance

Es una herramienta educativa de consulta histórica. No compra, vende, predice precios ni ofrece recomendaciones financieras.
